# Scenarios

A Scenario is versioned task/protocol context, not a scheduler or execution Profile.
Discover results.scenarios/get_scenario/scenario_graph and registration/link actions
with system.describe. Submit an optional exact scenario_ref on a Job or workflow.
Existing accepted Jobs retain their original revision; context changes never repin
work or duplicate datasets/models/experiments. Unassigned records remain valid.
Use explicit typed links with evidence. Do not infer historical protocols from
names or rewrite original provenance to make a catalog look complete.
